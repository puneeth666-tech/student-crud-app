# Student Management System

A simple CRUD web application built using HTML, CSS, Node.js, Express.js and MySQL.

## Features

- Add student
- View students
- Edit student details
- Delete student
- Store student data in MySQL database

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL
